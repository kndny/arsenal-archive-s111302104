# 槍械檔案館 Arsenal Archive

一個用圓點與「檔案終端機」風格整理槍械知識的互動網站。
收錄 **56 把**經典槍械、**6 種**槍種、**18 種**口徑，可以查資料、比規格、轉動 3D 模型，也能在小遊戲裡實際「開槍」。

> 課程：前端工程設計（國立臺北教育大學）
> 作者：吳吉恩

---

## 網站內容

| 頁面 | 可以做什麼 |
|---|---|
| 首頁 | 由圓點組成、會變形的槍（點一下換一把）、世界地圖、槍械簡史、術語說明、資料統計 |
| 槍種圖鑑 | 六種槍種：手槍、衝鋒槍、突擊步槍、步槍、機槍、霰彈槍。每把槍都有詳細檔案頁 |
| 篩選比較表 | 依槍種、地區、國家、年代、名稱篩選，勾選後可以並排比較 |
| 口徑對照 | 圓點子彈並排比大小，旁邊放一枚同比例的 10 元硬幣當對照 |
| 3D 展示 | 六種槍的示意 3D 模型：拖曳旋轉、查看零件、裝上配件、分解、播放射擊循環動畫 |
| 遊戲 | **試射場**：第一人稱試射，體驗後座力與彈著點<br>**防線**：守住防線的塔防遊戲，每一波可以挑選配件強化槍枝 |
| 收藏 | 把喜歡的槍收進「我的檔案夾」 |

### 互動特色
- 圖鑑卡片的圓點會被游標推開，點一下會整片炸開
- 文字裡的槍械術語滑過去就會顯示解釋
- 全站搜尋（按 `/` 開始輸入）
- 深色模式、音效開關、動態效果開關

## 使用的技術

- **HTML、CSS、JavaScript**，沒有使用任何框架或外部函式庫
- **Canvas**：首頁圓點變形、圓點子彈、3D 模型（自己寫的點雲 3D 繪製）、遊戲畫面
- **Hash 路由**（`#/catalog`、`#/gun/ak47`…）：整個網站是一個頁面，切換頁面不用重新載入
- **localStorage / sessionStorage**：記住收藏、比較清單、深色模式、音效與動態設定
- **Google Fonts**：Noto Serif TC、Noto Sans TC、Doto

## 設計規範

| 項目 | 內容 |
|---|---|
| 色彩（3 色） | 墨藍 `#17303F`、冷白 `#EDF0EE`、訊號黃 `#D9C45A` |
| 字型（3 種） | 標題 Noto Serif TC、內文 Noto Sans TC、點陣字 Doto（只用於英文與數字） |
| 字級（3 種） | 標題 3rem、副標 1.25rem、內文 1rem |
| 風格 | 「檔案終端機」：每把槍是一份檔案，搭配圓點（dot matrix）元素 |

## 無障礙與裝置

- 支援電腦與手機，手機上以點擊操作取代滑鼠滑過的效果
- 依照系統的「減少動態」設定自動關閉動畫，也可以用右上角的「動態」按鈕手動開關
- 深色模式預設跟隨系統設定
- 可以用鍵盤操作導覽與選單，圖片都有替代文字

## 檔案結構

```
arsenal-archive/
├─ index.html          網站唯一的 HTML 頁面
├─ css/template.css    所有樣式
├─ js/
│  ├─ main.js          槍枝資料、頁面切換、圖鑑、比較表、試射場
│  ├─ showcase.js      3D 展示（模型、配件、射擊循環）
│  ├─ defense.js       防線遊戲
│  ├─ calibers.js      口徑資料
│  ├─ gunextra.js      槍枝的補充資料
│  ├─ dotdata.js       圓點圖的資料
│  ├─ fx.js            首頁圓點變形
│  └─ feel.js          卡片特效、音效、動態開關
└─ images/
   ├─ photos/          槍枝照片（已去背）
   ├─ dots/            圓點版本的槍枝圖
   └─ favicon…         網站小圖示
```

## 怎麼開啟

- **線上：** 打開上方的網站連結
- **本機：** 下載整個資料夾後，直接雙擊 `index.html` 即可，不需要安裝任何東西
